# Altavera — lista de compra CENADA + fechas de entrega

Cambios:

1. La lista de compra del panel de pedidos muestra la referencia CENADA usada por la última corrida de precios completada, incluyendo precio normalizado y fecha de la fuente.
2. El checkout muestra como máximo las próximas 3 fechas de entrega disponibles.
3. No requiere migración SQL.

Después de copiar los archivos:

```bash
npm run build
```
